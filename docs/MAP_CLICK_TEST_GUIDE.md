# 地图点击精度测试指南

## 快速测试步骤

### 1. 基础功能测试

1. **打开应用**
   ```bash
   npm run dev
   ```

2. **创建带状航线任务**
   - 点击"创建航线"
   - 选择"带状航线"模式
   - 进入航线编辑界面

3. **测试不同缩放级别**

   **测试 A: 最小缩放（俯瞰）**
   - 缩小地图到最小级别
   - 点击地图添加第一个航点
   - 观察：航点标记应该准确出现在点击位置
   - ✅ 通过标准：航点位置偏差 < 10 米

   **测试 B: 中等缩放（城市级别）**
   - 缩放到可以看清街道的级别
   - 点击地图添加第二个航点
   - 观察：航点标记应该准确出现在点击位置
   - ✅ 通过标准：航点位置偏差 < 5 米

   **测试 C: 最大缩放（街道级别）**
   - 放大地图到最大级别
   - 点击地图添加第三个航点
   - 观察：航点标记应该准确出现在点击位置
   - ✅ 通过标准：航点位置偏差 < 1 米

### 2. 精度验证测试

1. **连续点击测试**
   - 在同一位置连续点击 3 次
   - 查看控制台输出的坐标
   - ✅ 通过标准：3 次坐标的偏差 < 0.00001 度（约 1 米）

2. **已知坐标测试**
   - 找一个已知坐标的地标（如建筑物角点）
   - 点击该位置
   - 对比实际坐标和点击坐标
   - ✅ 通过标准：偏差 < 0.00005 度（约 5 米）

### 3. 控制台日志检查

打开浏览器控制台（F12），查看点击日志：

```
Map clicked: { lat: 31.090123, lng: 104.390456, height: 0 }
```

**检查项**：
- ✅ 每次点击都有日志输出
- ✅ 坐标值合理（纬度 -90~90，经度 -180~180）
- ✅ 没有错误或警告信息

### 4. 边界条件测试

1. **快速连续点击**
   - 快速点击地图 5 次
   - ✅ 所有航点都应该正确添加

2. **地图边缘点击**
   - 点击地图视图的边缘位置
   - ✅ 航点应该正确添加

3. **地图拖动后点击**
   - 拖动地图到新位置
   - 立即点击添加航点
   - ✅ 航点位置应该准确

## 问题排查

### 问题 1: 航点位置偏移

**症状**: 航点标记不在点击位置

**排查步骤**:
1. 检查控制台是否有错误
2. 查看 `Map clicked` 日志中的坐标
3. 验证浏览器缩放比例是否为 100%
4. 尝试刷新页面

**解决方案**:
- 确保浏览器缩放为 100%
- 清除浏览器缓存
- 检查网络连接（地图瓦片加载）

### 问题 2: 点击无响应

**症状**: 点击地图没有添加航点

**排查步骤**:
1. 检查控制台是否有错误
2. 验证是否在正确的模式下（带状航线模式）
3. 检查地图是否完全加载

**解决方案**:
- 等待地图完全加载
- 刷新页面重试
- 检查浏览器控制台错误信息

### 问题 3: 坐标异常

**症状**: 控制台显示的坐标明显错误

**排查步骤**:
1. 查看完整的错误日志
2. 检查 Cesium 是否正确初始化
3. 验证地图图层是否加载

**解决方案**:
- 检查网络连接
- 重新加载页面
- 查看浏览器控制台的详细错误
