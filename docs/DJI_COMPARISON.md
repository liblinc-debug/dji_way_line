# 大疆司空带状航线参数对照表

## 参数对应关系

| 大疆司空参数 | 我们的实现 | 说明 |
|------------|----------|------|
| **选择镜头** | `cameraType` | |
| - 可见光 | `'visible'` | 可见光相机 |
| - 红外 | `'infrared'` | 红外相机 |
| **航线模式** | `routeMode` | |
| - 弓字航线 | `'zigzag'` | Z字形扫描，多条平行航线 |
| - 单航线 | `'single'` | 沿中心线单条航线 |
| **左外扩距离** | `leftExtension` | 中心线左侧扩展距离（米） |
| **右外扩距离** | `rightExtension` | 中心线右侧扩展距离（米） |
| **链接按钮** | `linkExtensions` | 链接左右扩展距离 |
| **切割距离** | `cuttingDistance` | 每个飞行段长度（米） |
| **GSD(可见光)** | `gsdVisible` | 地面采样距离（cm/pixel） |
| **GSD(红外)** | `gsdInfrared` | 红外地面采样距离（cm/pixel） |
| **航点高度模式** | `executeHeightMode` | |
| - 海拔高度 | `'WGS84'` | 绝对海拔高度 |
| - 相对起飞点高度 | `'relativeToStartPoint'` | 相对起飞点 |
| - 相对地形高度 | `'realTimeFollowSurface'` | 实时跟随地形 |
| **爬升模式** | `climbMode` | |
| - 垂直爬升 | `'vertical'` | 垂直上升到航线高度 |
| - 倾斜爬升 | `'inclined'` | 倾斜爬升，安全起飞高度 |
| **安全起飞高度** | `takeOffSecurityHeight` | 倾斜爬升时的安全高度（米） |
| **全局航线速度** | `globalSpeed` | 飞行速度（m/s） |
| **航线方向** | `routeDirection` | |
| - 平行于中心线 | `'parallel'` | 航线平行于中心线 |
| - 垂直于中心线 | `'perpendicular'` | 航线垂直于中心线 |
| **高程优化** | `elevationOptimization` | 自动优化飞行高度适应地形 |
| **边缘图像优化** | `edgeImageOptimization` | 优化边缘区域图像采集 |
| **完成动作** | `finishAction` | |
| - 自动返航 | `'goHome'` | 任务完成后返航 |
| - 悬停 | `'hover'` | 任务完成后悬停 |
| - 降落 | `'land'` | 任务完成后降落 |
