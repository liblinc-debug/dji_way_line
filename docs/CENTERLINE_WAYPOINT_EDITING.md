# 中心线航点编辑功能

## 功能概述

带状航线模式现在支持完整的中心线航点编辑功能，用户可以在"中心线航点"标签页中查看、编辑和管理中心线的航点。

## 实现细节

### 1. 标签页结构

在带状航线模式下，控制面板显示两个标签页：

- **带状航线配置**: 配置航线参数（外扩距离、切割距离、GSD等）
- **中心线航点**: 编辑中心线的航点坐标

### 2. 中心线航点列表功能

#### 2.1 显示内容
- 航点序号（中心点 1, 中心点 2, ...）
- 纬度和经度输入框（精度6位小数）
- 删除按钮（每个航点）

#### 2.2 操作功能
- **编辑坐标**: 直接在输入框中修改纬度/经度
- **删除航点**: 点击删除按钮移除单个航点
- **反转中心线**: 反转所有航点的顺序
- **清空航点**: 清空所有中心线航点

#### 2.3 提示信息
- 显示信息提示框，说明修改后航线会自动重新生成
- 建议至少保留2个航点
- 空状态提示用户在地图上点击添加航点

### 3. 实时更新机制

#### 3.1 自动重新生成
当中心线航点发生变化时（添加、删除、修改坐标），系统会自动：
1. 验证航点数量（至少2个）
2. 重新生成带状航线
3. 更新覆盖区域多边形
4. 更新航线统计信息

#### 3.2 防抖处理
- 使用300ms防抖延迟，避免频繁重新生成
- 提升性能和用户体验

### 4. 与其他模式的区别

#### 4.1 中心线模式 vs 普通航点模式

| 特性 | 中心线模式 | 普通航点模式 |
|------|-----------|-------------|
| 显示字段 | 纬度、经度 | 纬度、经度、高度、速度 |
| 航点名称 | 中心点 N | 航点 N |
| 用途 | 定义带状航线的中心路径 | 定义飞行器实际飞行的航点 |
| 高度控制 | 全局高度（在配置中） | 每个航点独立高度 |
| 速度控制 | 全局速度（在配置中） | 每个航点独立速度 |

### 5. 用户工作流程

1. **创建中心线**
   - 在地图上点击至少2个点
   - 系统自动生成初始航线

2. **调整参数**
   - 切换到"带状航线配置"标签
   - 调整外扩距离、切割距离等参数
   - 航线实时更新

3. **编辑中心线**
   - 切换到"中心线航点"标签
   - 修改航点坐标
   - 删除不需要的航点
   - 航线自动重新生成

4. **生成KMZ**
   - 点击"生成 KMZ"按钮
   - 下载航线文件
   - 导入到大疆设备

## 技术实现

### 组件结构

```
ControlPanel.vue
├── 带状航线模式判断 (isStripMode)
├── 标签页容器 (a-tabs)
│   ├── 带状航线配置 (StripRouteConfig)
│   └── 中心线航点 (WaypointList with isCenterline=true)
```

### 关键代码

#### ControlPanel.vue
```vue
<a-tabs v-if="isStripMode" v-model:activeKey="activeTab">
  <a-tab-pane key="strip-config" tab="带状航线配置">
    <StripRouteConfig ... />
  </a-tab-pane>
  <a-tab-pane key="centerline" tab="中心线航点">
    <WaypointList 
      :waypoints="waypoints" 
      :is-centerline="true"
      @update:waypoints="$emit('update:waypoints', $event)"
      ...
    />
  </a-tab-pane>
</a-tabs>
```

#### WaypointList.vue
```vue
<template v-if="!isCenterline">
  <!-- 显示高度和速度字段 -->
</template>
```

### 数据流

```
用户操作 → WaypointList
         ↓
    update:waypoints 事件
         ↓
    index.vue (watch)
         ↓
    generateStripRouteInternal()
         ↓
    更新 scanPath + coverageArea
         ↓
    MapViewer 渲染更新
```
