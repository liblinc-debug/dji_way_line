# 带状航线高级参数说明

## 参数列表

### 基础参数

#### 1. 选择镜头
- **类型**: 多选
- **选项**: 可见光、红外
- **默认**: 可见光
- **说明**: 至少选择一个镜头，可同时选择两个

#### 2. 航线模式
- **类型**: 单选
- **选项**: 弓字航线、单航线
- **默认**: 弓字航线
- **说明**: 
  - 弓字航线：多条平行航线覆盖，S型连接
  - 单航线：沿中心线飞行一条航线

#### 3. 左外扩距离 / 右外扩距离（弓字航线模式）
- **范围**: 5-500 米
- **默认**: 50 米
- **调整**: -100/-10/+10/+100
- **说明**: 
  - 中心线左右两侧的扩展距离
  - 可链接同步调整
  - 影响覆盖宽度

#### 4. 外扩距离（单航线模式）
- **范围**: 5-500 米
- **默认**: 50 米
- **调整**: -100/-10/+10/+100
- **说明**: 
  - 单航线模式下的外扩距离
  - 左右同步调整
  - 影响飞行高度

#### 5. 切割距离（弓字航线模式）
- **范围**: 50-5000 米
- **默认**: 1000 米
- **调整**: -100/-10/+10/+100
- **说明**: 
  - 每个飞行段的长度
  - 影响区域划分
  - 影响航点密度

---

### 高级参数

#### 6. 航向重叠率（弓字航线模式）
- **范围**: 0-90%
- **默认**: 70%
- **调整**: 滑块
- **说明**: 
  - 航线方向上的图像重叠率
  - 影响航点间距
  - 重叠率越高，航点越密集

#### 7. 旁向重叠率（弓字航线模式）
- **范围**: 0-90%
- **默认**: 70%
- **调整**: 滑块
- **说明**: 
  - 垂直航线方向上的图像重叠率
  - 影响航线间距
  - 重叠率越高，航线越密集

#### 8. 边距
- **范围**: 0-100 米
- **默认**: 0 米
- **调整**: -10/-1/+1/+10
- **说明**: 
  - 航线边界向外扩展的距离
  - 确保完全覆盖目标区域
  - 避免边缘遗漏

#### 9. 航线角度
- **范围**: -180° 到 180°
- **默认**: 0°
- **调整**: -45°/-5°/+5°/+45°
- **说明**: 
  - 航线相对于中心线的旋转角度
  - 0° = 平行于中心线
  - 90° = 垂直于中心线
  - 可用于优化拍摄角度

#### 10. 飞行速度
- **范围**: 1-15 m/s
- **默认**: 10 m/s
- **调整**: -5/-1/+1/+5
- **说明**: 
  - 飞行器在航线上的飞行速度
  - 影响飞行时间
  - 影响图像质量（速度越快，可能模糊）

#### 11. 飞行高度
- **范围**: 20-500 米
- **默认**: 50 米
- **调整**: -50/-10/+10/+50
- **说明**: 
  - 飞行器相对于起飞点的高度
  - 影响覆盖范围
  - 影响图像分辨率
  - 必须满足最小飞行高度要求

---

### GSD 配置

#### 12. GSD（可见光）
- **范围**: 0.1+ cm/pixel
- **默认**: 5 cm/pixel
- **调整**: -1/-0.1/+0.1/+1
- **说明**: 
  - Ground Sample Distance（地面采样距离）
  - 影响图像分辨率
  - 值越小，分辨率越高

#### 13. GSD（红外）
- **范围**: 0.1+ cm/pixel
- **默认**: 14.06 cm/pixel
- **调整**: -1/-0.1/+0.1/+1
- **说明**: 
  - 红外相机的地面采样距离
  - 通常比可见光相机的GSD大

---

### 其他参数

#### 14. 航线方向
- **类型**: 下拉选择
- **选项**: 平行于中心线、垂直于中心线
- **默认**: 平行于中心线
- **说明**: 
  - 航线相对于中心线的方向
  - 影响飞行路径规划

#### 15. 高程优化
- **类型**: 开关
- **默认**: 开启
- **说明**: 
  - 自动优化飞行高度以适应地形
  - 保持相对地面高度一致

#### 16. 边缘图像优化
- **类型**: 开关
- **默认**: 关闭
- **说明**: 
  - 优化边缘区域的图像采集
  - 确保边缘区域的图像质量

## 参数关系

### 覆盖宽度
```
总宽度 = 左外扩距离 + 右外扩距离
```

### 航线数量（弓字航线）
```
有效宽度 = 总宽度 × (1 - 旁向重叠率 / 100)
航线数量 = ceil(总宽度 / 有效宽度)
```

### 航点间距（弓字航线）
```
有效切割距离 = 切割距离 × (1 - 航向重叠率 / 100)
航点间距 ≈ 有效切割距离
```

### 最小飞行高度
```
最小高度 = max(左外扩距离, 右外扩距离) × 安全系数
```

### 覆盖面积
```
覆盖面积 = 中心线长度 × 总宽度
```

### 预计飞行时间
```
总航程 = 所有航点之间的距离总和
飞行时间 = 总航程 / 飞行速度
```

## 参数优化建议

### 1. 高分辨率拍摄
- GSD: 2-3 cm/pixel
- 飞行高度: 30-50 米
- 飞行速度: 5-8 m/s
- 重叠率: 80%

### 2. 快速覆盖
- GSD: 8-10 cm/pixel
- 飞行高度: 80-120 米
- 飞行速度: 12-15 m/s
- 重叠率: 60%

### 3. 平衡模式（推荐）
- GSD: 5 cm/pixel
- 飞行高度: 50 米
- 飞行速度: 10 m/s
- 重叠率: 70%

### 4. 复杂地形
- 高程优化: 开启
- 边距: 10-20 米
- 重叠率: 75-80%
- 飞行速度: 8-10 m/s
