# 带状航线功能使用指南

## 功能概述

带状航线规划功能用于生成沿指定中心线的带状扫描航线，适用于：
- 🌊 河流巡检
- 🛣️ 道路监测
- ⚡ 电力线巡检
- 🚂 铁路巡检
- 🌉 桥梁检测

## 快速开始

### 1. 创建带状航线任务

1. 点击"创建新航线"按钮
2. 在"测绘航线"分类中选择"带状航线"
3. 选择飞行器型号
4. 输入航线名称
5. 点击"确定"

### 2. 绘制中心线

在地图上点击至少 2 个点来绘制中心线路径：
- 第一个点：起点
- 中间点：路径转折点
- 最后一个点：终点

💡 **提示**：中心线应该沿着需要巡检的目标（如河流、道路）绘制

### 3. 配置参数

#### 航线模式
- **单航线**：沿中心线飞行一条航线
- **Z字形**：生成多条平行航线，实现更宽的覆盖

#### 扩展长度
- **左侧扩展**：中心线左侧的覆盖距离（米）
- **右侧扩展**：中心线右侧的覆盖距离（米）
- **链接左右**：开启后，左右扩展长度保持一致

💡 **建议值**：
- 河流巡检：50-100米
- 道路监测：30-50米
- 电力线巡检：20-40米

#### 切割距离
每个飞行段的长度，影响航点密度
- 较小值（50-100米）：航点更密集，适合精细巡检
- 较大值（200-500米）：航点较少，适合快速巡检

#### 航线重叠率（仅Z字形模式）
相邻航线之间的重叠程度（30-90%）
- 高重叠率：更好的覆盖，但飞行时间更长
- 低重叠率：飞行时间短，但可能有覆盖空隙

#### 航线角度
调整航线方向（0-180度）
- 0°：南北向
- 90°：东西向
- 其他角度：根据实际需求调整

### 4. 查看预览

系统会实时生成航线预览，显示：
- 🔵 中心线（蓝色）
- 🟢 扫描航线（绿色）
- 📊 统计信息：航点数、航程、预计时间、覆盖面积

### 5. 导出 KMZ

点击"生成 KMZ"按钮，导出符合 WPML 1.0.6 标准的航线文件，可直接导入大疆司空 2 或 Matrice 系列无人机。

## 参数说明

### 最小飞行高度

系统会根据扩展长度自动计算建议的最小飞行高度：

```
最小高度 = 最大扩展长度 / tan(30°)
```

⚠️ **警告**：如果当前飞行高度低于建议值，可能无法完全覆盖带宽

### 航线统计

- **航点数**：生成的航点总数
- **航程**：总飞行距离（米）
- **预计时间**：基于飞行速度的预计飞行时间（分钟）
- **覆盖面积**：带状区域的总面积（公顷）
- **中心线长度**：中心线的总长度（米）
- **航线数**：Z字形模式下的平行航线数量

## 使用技巧

### 1. 河流巡检

```
推荐配置：
- 航线模式：Z字形
- 左右扩展：各 50-100 米
- 切割距离：100-200 米
- 重叠率：70%
- 飞行高度：80-120 米

- 航线模式：单航线
- 左右扩展：各 30-50 米
- 切割距离：50-100 米
- 飞行高度：50-80 米

推荐配置：
- 航线模式：单航线
- 左右扩展：各 20-40 米

- 飞行高度：40-60 米
```

## 常见问题

### Q: 为什么无法生成航线？

A: 请检查：
1. 中心线是否至少有 2 个点
2. 扩展长度是否在有效范围内（5-500米）
3. 切割距离是否在有效范围内（50-5000米）
4. 飞行高度是否满足最小高度要求

### Q: 如何调整航线密度？

A: 通过以下参数调整：
- **切割距离**：减小切割距离可增加航点密度
- **重叠率**（Z字形模式）：增加重叠率可增加航线密度

### Q: Z字形模式生成了多少条航线？

A: 航线数量由以下公式计算：

```
航线数 = 总宽度 / (总宽度 × (1 - 重叠率))
```

例如：总宽度 100米，重叠率 70%，则航线数 ≈ 4 条

### Q: 如何优化飞行时间？

A: 可以通过以下方式优化：
1. 增加切割距离（减少航点数）
2. 降低重叠率（减少航线数）
3. 提高飞行速度（注意影响拍摄质量）
4. 使用单航线模式（如果覆盖宽度允许）
