# 带状航线快速开始指南

## 5 分钟快速上手

### 第一步：启动应用

```bash
# 确保已安装依赖
npm install

# 启动开发服务器
npm run dev
```

访问 http://localhost:5176/

---

### 第二步：创建带状航线任务

1. 点击主界面的 **"创建新航线"** 按钮
2. 在弹出的对话框中选择 **"带状航线"**
3. 输入任务名称（如："河流巡检"）
4. 点击 **"确认"**

![创建任务](./images/create_mission.png)

---

### 第三步：绘制中心线

在地图上点击至少 **2 个点** 来绘制中心线：

1. 第一次点击：设置起点
2. 第二次点击：设置终点
3. 继续点击：添加更多转折点（可选）

💡 **提示**: 中心线代表你想要扫描的路径中心，比如河流中心线、道路中心线等。

---

### 第四步：配置参数

#### 1. 选择镜头（必选）

- **可见光**: 适合日间拍摄，默认 GSD 5 cm/pixel
- **红外**: 适合热成像，默认 GSD 14.06 cm/pixel
- 💡 可以同时选择两种镜头

#### 2. 选择航线模式

- **弓字航线** (推荐): 多条平行航线，覆盖更广
- **单航线**: 沿中心线飞行，速度更快

#### 3. 调整覆盖范围

使用 **左外扩距离** 和 **右外扩距离** 控制扫描宽度：

- 点击 **+10** / **+100** 增加距离
- 点击 **-10** / **-100** 减少距离
- 点击 **🔗 链接** 按钮可以同步左右距离

💡 **建议值**:
- 河流巡检: 50-100m
- 道路监测: 30-50m
- 电力线巡检: 20-40m

#### 4. 设置切割距离

**切割距离** 决定航点的密度：

- **较小值** (50-200m): 航点密集，拍摄更详细
- **较大值** (500-1000m): 航点稀疏，飞行更快

💡 **默认值**: 1000m（适合大多数场景）

---

### 第五步：查看实时预览

配置参数后，系统会自动生成航线预览：

- **绿色半透明区域**: 扫描覆盖范围 🆕
- **红色线条**: 飞行路径
- **蓝色线条**: 中心线
- **红色点**: 航点位置
- **统计卡片**: 显示航点数、航程、预计时间等

💡 **提示**: 修改任何参数后，航线和覆盖区域会在 300ms 后自动更新。

---

### 第六步：生成 KMZ 文件

1. 确认参数配置无误
2. 点击顶部的 **"生成 KMZ"** 按钮
3. 文件会自动下载到本地

💡 **文件名**: 任务名称.kmz（如："河流巡检.kmz"）

---

### 第七步：导入到大疆设备

1. 将 KMZ 文件传输到大疆遥控器或司空平台
2. 在大疆设备上导入航线
3. 开始执行任务

---

## 高级技巧

### 技巧 1: 优化飞行高度

系统会根据外扩距离自动计算 **建议最小飞行高度**：

- 如果当前高度低于建议值，会显示黄色警告
- 建议按照提示调整高度，确保完全覆盖

### 技巧 2: 使用链接功能

当左右外扩距离相同时：

1. 点击 **🔗 链接** 按钮
2. 调整左外扩距离时，右外扩会自动同步
3. 节省配置时间

### 技巧 3: 快速调整参数

使用按钮快速调整：

- **+100 / -100**: 大幅调整
- **+10 / -10**: 精细调整
- **+1 / -1**: GSD 大幅调整
- **+0.1 / -0.1**: GSD 精细调整

### 技巧 4: 实时预览

- 修改参数后无需手动刷新
- 系统会自动更新预览（300ms 防抖）
- 如需立即更新，点击 **"手动刷新航线"**

## 常见问题

### Q1: 为什么无法生成航线？

**可能原因**:
- 中心线点数少于 2 个
- 没有选择任何镜头
- 参数超出有效范围

**解决方法**: 检查左侧面板的错误提示，按提示修改。

---

### Q2: 航点数量太多怎么办？

**解决方法**:
- 增加切割距离（如从 200m 改为 500m）
- 减少中心线的转折点
- 使用单航线模式代替弓字航线

---

### Q3: 如何确保完全覆盖目标？

**建议**:
1. 适当增加左右外扩距离
2. 减小切割距离，增加航点密度
3. 使用弓字航线模式
4. 开启高程优化和边缘图像优化

---

### Q4: 生成的 KMZ 文件无法导入？

**检查项**:
- 文件是否完整下载
- 大疆设备是否支持 WPML 1.0.6 格式
- 航点数量是否超过设备限制

---

### Q5: 如何修改已生成的航线？

**方法**:
1. 在左侧面板修改参数
2. 系统会自动重新生成航线
3. 重新导出 KMZ 文件

## 性能建议

### 推荐配置

- **浏览器**: Chrome 最新版
- **屏幕分辨率**: 1920x1080 或更高
- **内存**: 8GB 或更高

### 性能优化

- 避免绘制过于复杂的中心线（建议 < 50 个点）
- 避免生成过多航点（建议 < 3000 个）
- 关闭不必要的浏览器标签页
