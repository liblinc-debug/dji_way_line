# 航线模式参数差异说明

## 概述

弓字航线和单航线模式在参数配置上有显著差异，以适应不同的飞行需求和场景。

## 参数对比

### 弓字航线模式

**适用场景**: 需要覆盖较宽区域的扫描任务

**参数配置**:

| 参数 | 说明 | 范围 | 默认值 |
|------|------|------|--------|
| 左外扩距离 | 中心线左侧的扫描宽度 | 5-500m | 50m |
| 右外扩距离 | 中心线右侧的扫描宽度 | 5-500m | 50m |
| 链接按钮 | 同步左右外扩距离 | - | 已链接 |
| 切割距离 | 每个飞行段的长度 | 50-5000m | 1000m |

**特殊功能**:
- ✅ 合并测区按钮
- ✅ 翻转测区按钮
- ✅ 左右外扩距离可独立调整
- ✅ 链接功能可同步左右距离

**飞行模式**:
- 生成多条平行航线
- S 形连接路径
- 完整覆盖带状区域

---

### 单航线模式

**适用场景**: 沿中心线飞行，外扩距离影响飞行高度

**参数配置**:

| 参数 | 说明 | 范围 | 默认值 |
|------|------|------|--------|
| 外扩距离 | 单一外扩参数 | 5-500m | 50m |

**特殊功能**:
- ✅ 翻转测区按钮
- ❌ 无合并测区按钮
- ❌ 无切割距离配置
- ❌ 无左右独立调整

**飞行模式**:
- 沿中心线飞行单条航线
- 外扩距离影响飞行高度
- 适合窄带目标

**说明文字**:
> 此模式下，飞行器将沿中心线飞一条航线，外扩距离将会影响飞行高度

## 技术实现

### 条件渲染

```vue
<!-- 弓字航线模式：左外扩距离 + 右外扩距离 -->
<template v-if="localConfig.routeMode === 'zigzag'">
  <!-- 左外扩距离 -->
  <a-form-item label="左外扩距离">
    <!-- ... -->
  </a-form-item>
  
  <!-- 右外扩距离 -->
  <a-form-item label="右外扩距离">
    <!-- ... -->
  </a-form-item>
</template>

<!-- 单航线模式：外扩距离（单一参数） -->
<template v-else>
  <a-form-item label="外扩距离">
    <!-- ... -->
    <div class="text-xs text-gray-500 mt-1">
      此模式下，飞行器将沿中心线飞一条航线，外扩距离将会影响飞行高度
    </div>
  </a-form-item>
</template>
```

### 参数调整逻辑

**弓字航线模式**:
```javascript
// 可以独立调整左右外扩距离
const adjustExtension = (side, delta) => {
  if (side === 'left') {
    localConfig.value.leftExtension += delta;
    if (localConfig.value.linkExtensions) {
      localConfig.value.rightExtension = localConfig.value.leftExtension;
    }
  } else {
    localConfig.value.rightExtension += delta;
  }
};
```

**单航线模式**:
```javascript
// 左右外扩距离同时调整
const adjustSingleExtension = (delta) => {
  const newValue = localConfig.value.leftExtension + delta;
  localConfig.value.leftExtension = newValue;
  localConfig.value.rightExtension = newValue;
};
```

## 使用场景对比

### 弓字航线适用场景

1. **河流巡检**
   - 需要覆盖河流两岸
   - 左右外扩距离可能不同（一侧有建筑物）
   - 需要多条平行航线确保覆盖

2. **道路监测**
   - 覆盖道路及两侧区域
   - 左右外扩可能不对称
   - 切割距离控制航点密度

3. **电力线巡检**
   - 覆盖电力线走廊
   - 多条航线确保无遗漏
   - 切割距离适应杆塔间距

### 单航线适用场景

1. **管道巡检**
   - 沿管道中心线飞行
   - 外扩距离影响飞行高度
   - 单条航线即可满足需求

2. **窄带目标**
   - 目标宽度较小
   - 不需要多条航线
   - 简化参数配置

3. **快速巡检**
   - 需要快速完成任务
   - 单条航线飞行时间短
   - 外扩距离确保覆盖范围

## 参数联动关系

### 弓字航线模式

```
左外扩距离 ←→ [链接按钮] ←→ 右外扩距离
     ↓                           ↓
  覆盖区域左边界            覆盖区域右边界
     ↓                           ↓
        ↘                     ↙
          总覆盖宽度 = 左 + 右
                ↓
          航线数量 = 总宽度 / 有效宽度
                ↓
          切割距离 → 航点密度
```

### 单航线模式

```
外扩距离
    ↓
左外扩 = 右外扩 = 外扩距离
    ↓
总覆盖宽度 = 外扩距离 × 2
    ↓
影响飞行高度
```

## 切换模式时的行为

### 从弓字航线切换到单航线

1. **保留参数**: 左外扩距离
2. **同步参数**: 右外扩距离 = 左外扩距离
3. **隐藏参数**: 切割距离（不再使用）
4. **隐藏按钮**: 合并测区按钮

### 从单航线切换到弓字航线

1. **保留参数**: 外扩距离 → 左外扩距离
2. **同步参数**: 右外扩距离 = 左外扩距离
3. **显示参数**: 切割距离（使用默认值 1000m）
4. **显示按钮**: 合并测区按钮

## 常见问题

### Q1: 为什么单航线模式没有切割距离？

A: 单航线模式沿中心线飞行单条航线，航点密度由中心线的复杂度决定，不需要切割距离参数。

### Q2: 单航线模式的外扩距离如何影响飞行高度？

A: 外扩距离越大，需要的飞行高度越高，以确保相机能够覆盖整个外扩范围。

### Q3: 切换模式后参数会丢失吗？

A: 不会。切换模式时会保留外扩距离参数，只是显示方式不同。

### Q4: 弓字航线模式下，左右外扩距离必须相同吗？

A: 不必须。可以取消链接，独立调整左右外扩距离，适应不对称的扫描需求。

## 总结

弓字航线和单航线模式的参数差异设计，使得每种模式都能更好地适应其特定的使用场景。弓字航线提供更多的参数控制，适合复杂的覆盖任务；单航线简化参数配置，适合快速的线性巡检任务。
