## 功能简介

带状航线规划是一个专为 DJI 无人机设计的线性目标扫描航线生成工具。通过绘制中心线和配置扫描参数，系统可以自动生成符合 WPML 1.0.6 标准的航线文件，适用于河流巡检、道路监测、电力线巡检等场景。

### 主要优势

- ✅ **完全匹配大疆司空**: 参数和界面与大疆官方保持一致
- ✅ **实时预览**: 参数调整后 300ms 自动更新航线
- ✅ **智能提示**: 自动计算最小飞行高度，参数验证
- ✅ **灵活配置**: 支持单航线和弓字航线两种模式
- ✅ **多相机支持**: 可同时配置可见光和红外相机
- ✅ **一键导出**: 生成标准 KMZ 文件，直接导入大疆设备

## 快速开始

### 1. 启动应用

```bash
npm install
npm run dev
```

访问 http://localhost:5176/

### 2. 创建任务

1. 点击"创建新航线"
2. 选择"带状航线"
3. 输入任务名称

### 3. 绘制中心线

在地图上点击至少 2 个点绘制中心线

### 4. 配置参数

- 选择镜头（可见光/红外）
- 设置左右外扩距离
- 选择航线模式
- 调整其他参数

### 5. 生成 KMZ

点击"生成 KMZ"按钮，下载航线文件

📖 **详细教程**: [快速开始指南](./QUICK_START.md)

## 核心特性

### 🎯 中心线绘制

- 地图点击添加航点
- 支持多个转折点
- 实时显示中心线路径

### 📷 相机配置（多选）

| 相机类型 | 默认 GSD | 适用场景 |
|---------|---------|---------|
| 可见光 | 5 cm/pixel | 日间拍摄、地形测绘 |
| 红外 | 14.06 cm/pixel | 热成像、夜间巡检 |

- 支持同时选择两种相机
- 至少选择一个相机
- GSD 值可精确调整

### 🛤️ 航线模式

#### 弓字航线（推荐）
- 多条平行航线
- S 形连接
- 覆盖范围广

#### 单航线
- 沿中心线飞行
- 速度快
- 适合窄带目标

### ⚙️ 参数配置

| 参数 | 范围 | 默认值 | 说明 |
|------|------|--------|------|
| 左外扩距离 | 5-500m | 50m | 中心线左侧扫描宽度 |
| 右外扩距离 | 5-500m | 50m | 中心线右侧扫描宽度 |
| 切割距离 | 50-5000m | 1000m | 航点间隔 |
| 飞行速度 | 1-15 m/s | 10 m/s | 飞行速度 |
| 飞行高度 | 20-500m | 50m | 相对高度 |

### 📊 实时统计

- 航点数量
- 总航程（米）
- 预计飞行时间（分钟）
- 覆盖面积（公顷）
- 中心线长度（米）

### 🔍 智能提示

- **最小高度计算**: 根据外扩距离自动计算建议高度
- **参数验证**: 实时检查参数有效性
- **错误提示**: 清晰的错误信息和修复建议

## 使用场景

### 🌊 河流巡检

**配置建议**:
- 镜头: 可见光
- 模式: 弓字航线
- 外扩: 80m × 80m
- 切割: 500m

**适用于**: 河流污染监测、河道变化监测、水质检查

---

### 🛣️ 道路监测

**配置建议**:
- 镜头: 可见光
- 模式: 单航线
- 外扩: 30m × 30m
- 切割: 200m

**适用于**: 道路巡检、交通监控、路面检查

---

### ⚡ 电力线巡检

**配置建议**:
- 镜头: 可见光 + 红外
- 模式: 单航线
- 外扩: 20m × 20m
- 切割: 100m

**适用于**: 电力线检查、热点检测、设备巡检

---

### 🔧 管道巡检

**配置建议**:
- 镜头: 红外
- 模式: 单航线
- 外扩: 15m × 15m
- 切割: 50m

**适用于**: 管道泄漏检测、热损失监测

## 技术架构

### 核心组件

```
StripRouteConfig.vue          # UI 配置组件
├── 参数输入表单
├── 实时预览控制
└── 统计信息显示

stripRouteGenerator.js        # 航线生成算法
├── 单航线生成
├── 弓字航线生成
└── S 形路径连接

geometryCalculator.js         # 几何计算引擎
├── 距离计算
├── 方位角计算
└── 平行线生成

parameterValidator.js         # 参数验证器
├── 范围验证
├── 逻辑验证
└── 安全检查
```

### 技术栈

- **前端框架**: Vue 3
- **地图引擎**: CesiumJS
- **UI 组件**: Ant Design Vue
- **构建工具**: Vite
- **语言**: JavaScript

### 数据流

```
用户输入 → 参数验证 → 航线生成 → 地图渲染 → KMZ 导出
   ↓           ↓           ↓           ↓           ↓
 表单组件   验证器    生成算法    Cesium    WPML 格式
```

## 常见问题

### Q: 如何确保完全覆盖目标？

A: 适当增加左右外扩距离，减小切割距离，使用弓字航线模式。

### Q: 航点数量太多怎么办？

A: 增加切割距离，减少中心线转折点，或使用单航线模式。

### Q: 生成的 KMZ 无法导入？

A: 检查文件完整性，确认设备支持 WPML 1.0.6 格式。
